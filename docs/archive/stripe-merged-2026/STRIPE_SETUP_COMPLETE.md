## 📝 Important Notes

### Stripe Price IDs
**Note**: Stripe doesn't allow custom IDs for prices (only products). The actual Stripe price IDs are:
- Auto-generated by Stripe (e.g., `price_1SlDViI7vbumyzaW5pKm9Yus`)
- Stored in database `stripePriceId` field
- Used automatically by subscription services

### Custom Product IDs
Products DO have custom IDs (e.g., `prod_pro`, `prod_business_basic`) which makes them easy to reference.

### Environment
Currently using **TEST mode** (`sk_test_`). For production:
1. Switch to live keys (`sk_live_`)
2. Re-run `pnpm stripe:setup` to create products in live mode
3. Re-run `pnpm stripe:sync` to sync live price IDs
