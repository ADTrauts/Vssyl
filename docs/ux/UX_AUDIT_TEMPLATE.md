# UX Audit Template

**Status:** Reusable worksheet — copy per module review.  
**Do not use this file alone for certification** — scores must follow [`UX_CERTIFICATION_SCORECARD.md`](./UX_CERTIFICATION_SCORECARD.md).

**Instructions:**

1. Copy this template to `docs/ux/audits/{MODULE}_UX_AUDIT_{DATE}.md` when performing Wave 4 reviews.
2. Score each section 0–5 using scorecard definitions.
3. Attach evidence (screenshots, PR links, grep results).
4. Link remediation items to a wave in [`UX_MODERNIZATION_ROADMAP.md`](./UX_MODERNIZATION_ROADMAP.md).
5. Do not assign UX-L2/L3 in this template without reviewer sign-off.
